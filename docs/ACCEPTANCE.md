## 2. 全栈冒烟测试

环境：PostgreSQL 18（embedded）+ Redis 7.2.5 + `main-api` / `main-collector` / `main-mailer` 三个进程 + 本地 SSH 服务端（forced command 运行真实采集脚本）+ 真实 `ccusage@20.0.23` 读取本机 `~/.claude`。

| 步骤 | 结果 |
| --- | --- |
| 首次启动迁移并创建初始管理员 | 通过 |
| 录入私钥 → 返回指纹，不回显 | 通过 |
| 未确认主机指纹时采集 | 按预期失败：`HOST_KEY_UNVERIFIED` |
| 扫描并确认指纹 → 测试连接 → 测试目录 | 通过（`collectorVersion 1.0.0`，`ccusage 20.0.23`，`logFiles 6`） |
| 手动采集（经 BullMQ 入队，Worker 执行） | 通过：`init` 运行，范围 2026-06-21～2026-09-19，入库 1 行 |
| 月预算规则（80%/100%，预算 US$1，实际约 US$15） | 通过：两档各一条记录，仅 100% 进入发件箱，80% 标注“已触发更高档位” |
| 未配置 SMTP | 通过：邮件保留在发件箱并告警日志，不消耗重试次数 |
| 22:00:00（Asia/Shanghai）定时时点 | 通过：自动创建 `scheduled` 批次，范围 2026-09-16～2026-09-19，采集成功，未重复告警 |
| 前端联调（无头 Firefox 登录后依次打开 8 个页面） | 通过：全部页面无运行时错误、无接口 5xx，图表与数据正常渲染 |

冒烟测试中发现并修复：① Token 合计以字符串返回（`sum(bigint)` 为 numeric）→ 显式转回 bigint；② 无请求体的动作型 POST 带 JSON content-type 时被拒 → 在入口处理；③ 用户列表接口因同一参数同时用于 date 与 text 列而报错 → 显式类型转换；④ 前端重建后新资源文件未被静态路由识别 → 改为通配模式并回退到单页入口。①②③ 已补回归测试。
